# 🎵 Presence - Your Music, Your Status, Everywhere

## 🚀 What is Presence?

Presence is a magical little program that shows what you're working on in your Discord profile. When you're producing music in a studio, writing code, or designing something creative, Presence automatically tells your friends and communities what you're doing - without you having to lift a finger.

Think of it like a friendly assistant that posts "Hey, I'm working on something cool!" to your Discord profile, but with all the exciting details - like what program you're using and what you're creating.

## ✨ Key Features

- **Automatic Detection** – Presence quietly watches what creative programs you're using and updates your Discord status instantly
- **Multi-Platform Support** – Works with music production software, coding tools, and design applications
- **Real-Time Updates** – Your status changes the moment you switch between different projects
- **Message Customization** – Show off what you're working on with optional details like project names or files
- **Simple Interface** – No confusing settings; just install, turn on, and forget it

## 🎮 How It Works

Here's what Presence does behind the scenes (but we promise, there's no technical know-how needed):

1. **Watch** – It keeps an eye on which apps you're using that are supported
2. **Connect** – It talks to Discord using the official Rich Presence system
3. **Display** – Your profile now shows your current activity, complete with custom messages you can set up

## 🧪 Troubleshooting Tips

If something doesn't work right away, here are a few things to try:

**App doesn't start?**  
Make sure Discord is running, then try opening Presence again.

**Status not updating?**  
Right-click the Presence icon in your system tray (bottom-right corner) and select "Refresh Connection."

**Still stuck?**  
Restart your computer, then launch both Discord and Presence again. This usually fixes everything.
